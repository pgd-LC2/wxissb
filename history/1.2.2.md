# 版本 1.2.2

## 更新日期
2026-01-31

## 新功能

### 技能选择时全局暂停
- 当任意玩家升级选择技能时，整个游戏会暂停（包括 Host 的模拟）
- 队友会看到"XXX 正在选择技能..."的提示界面
- 选择完成后游戏自动恢复

## 技术实现

### 新增广播事件
- 在 `room.js` 中添加 `skill_selecting` 广播事件监听
- 新增 `sendSkillSelecting(isSelecting, playerName)` 方法用于广播技能选择状态

### multiplayerTick.js 修改
- 添加技能选择暂停状态属性：`skillSelectingPlayerId`、`skillSelectingPlayerName`
- 添加 `onSkillSelectingChange` 回调用于通知 UI 更新
- 添加 `handleSkillSelectingMessage()` 处理队友的技能选择状态
- 添加 `sendSkillSelecting(isSelecting)` 方法广播本地技能选择状态
- 当队友开始选择技能时暂停游戏，完成后恢复

### lobby.js 修改
- `showSkillSelection()` 方法在显示技能选择界面前广播开始选择状态
- `selectSkill()` 方法在选择完成后广播结束选择状态
- 新增 `handleTeammateSkillSelecting()` 方法显示/隐藏队友选择技能提示
- 在 `initGame()` 中设置 `onSkillSelectingChange` 回调

### CSS 样式
- 新增 `.teammate-selecting-overlay` 队友选择技能提示覆盖层样式
- 包含加载动画和提示文字
