# 版本 1.3.3 更新日志

**发布日期**: 2026-02-05

## 新增功能

### 职业和武器选择系统

**功能描述**：
- 在游戏开始时添加了职业和武器选择界面，让玩家能够自定义角色风格

**职业系统**：
1. **法师 (Mage)**
   - 伤害 +30%
   - 血量 -20%
   - 暴击率 +10%
   - 暴击伤害 +20%
   - 初始带有燃烧效果
   - 经验获取 +10%

2. **战士 (Warrior)**
   - 血量 +40%
   - 伤害 -10%
   - 减伤 +15%
   - 每秒回血
   - 击退力增强
   - 反伤效果

3. **刺客 (Assassin)**
   - 暴击率 +20%
   - 暴击伤害 +50%
   - 移动速度 +25%
   - 血量 -15%
   - 闪避 8%
   - 射速提升
   - 击杀回血

**武器系统**：
1. **狙击枪 (Sniper Rifle)**
   - 伤害 +80%
   - 射速 -50%
   - 穿透 +2
   - 子弹速度 +40%
   - 击退增强

2. **突击步枪 (Assault Rifle)**
   - 伤害 +15%
   - 射速 +20%
   - 穿透 +1
   - 平衡型武器

3. **冲锋枪 (SMG)**
   - 伤害 -30%
   - 射速 +100%（翻倍）
   - 每次发射 2 颗子弹
   - 散布角度较大

**UI界面**：
- 现代化的分步选择界面
- 职业和武器卡片带有详细的属性说明
- 选择完成后显示确认面板
- 支持返回修改选择
- HUD 显示当前选择的职业和武器

**实现方案**：
1. 创建 classWeaponSystem.js 模块，包含职业和武器数据结构
2. 实现属性应用函数，支持乘法和加法两种修正方式
3. 创建完整的选择界面 UI
4. 集成到游戏启动流程，游戏开始前必须选择职业和武器
5. 重新开始游戏时也会显示选择界面

**修改文件**：
- `js/classWeaponSystem.js` - 新增职业和武器系统模块
- `js/bootstrap.js` - 修改启动流程集成选择界面
- `js/ui/hud.js` - 添加职业武器徽章显示
- `pages/game.html` - 添加 classWeaponSystem.js 引用和徽章元素
- `css/styles.css` - 添加选择界面和徽章样式
- `version.txt` - 版本号更新至 1.3.3
