# 版本 1.7.11 更新日志

**发布日期**: 2026-04-16

## 新增功能 / 修复内容

### 结构重构：目录扁平化与入口收口落地

**问题描述**：
- 游戏/首页/排行榜仍依赖分散的目录文件，脚本路径较深，入口维护成本高。
- 目录单文件结构较多，导致后续重构和迁移成本上升。
- 目录折叠与入口收口后未统一落地。

**修复方案 / 实现方案**：
1. 保持 `window.GameApp` 命名空间不变，按既有加载顺序不改逻辑地重整文件结构。
2. 将以下单文件目录折叠到父目录：
   - `js/content/config/supabaseConfig.js` -> `js/content/supabaseConfig.js`
   - `js/content/classes/classWeaponData.js` -> `js/content/classWeaponData.js`
   - `js/content/skills/cyberSkills.js` -> `js/content/cyberSkills.js`
   - `js/content/skills/bladeSkills.js` -> `js/content/bladeSkills.js`
   - `js/infra/storage/preferences.js` -> `js/infra/preferences.js`
   - `js/infra/storage/playerNameStore.js` -> `js/infra/playerNameStore.js`
   - `js/infra/api/supabaseClient.js` -> `js/infra/supabaseClient.js`
   - `js/infra/api/leaderboardApi.js` -> `js/infra/leaderboardApi.js`
   - `js/infra/api/skillReportApi.js` -> `js/infra/skillReportApi.js`
   - `js/ui/home/homePage.js` -> `js/ui/homePage.js`
   - `js/ui/leaderboard/leaderboardPage.js` -> `js/ui/leaderboardPage.js`
   - `js/ui/game/classWeaponSelect.js` 与 `js/ui/game/controls.js` 合并到 `js/uiGame.js`
   - `js/input/joystick.js` / `js/input/joystickDialog.js` / `js/input/keyboard.js` 合并到 `js/input.js`
   - `js/ui/shared/skillCards.js` / `js/ui/shared/scoreSummary.js` / `js/ui/shared/skillReport.js` 合并到 `js/uiShared.js`

   - `js/app/bootstrap/gameEntry.js`
