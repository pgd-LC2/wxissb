# 版本 1.7.0 更新日志

**发布日期**: 2026-03-19

## 新增功能 / 修复内容

### 飞刀数量UI显示

**问题描述**：
- 玩家无法在HUD中看到当前飞刀（Blade Orbit）数量

**实现方案**：
1. 在游戏HUD中增加飞刀数量显示（🔪 飞刀: X）
2. 实时更新飞刀数量，无飞刀时自动隐藏

### 难度系统重构（Sigmoid平滑曲线）

**问题描述**：
- 移除log函数后战力数值增长过快，导致前期太难、后期太简单

**实现方案**：
1. 使用Sigmoid函数替代原有线性难度计算，将战力比值压缩到0.5-1.5范围
2. 最终难度 = 基准难度 * (0.8 + clampedRatio * 0.7)
3. 新增滑动平均战力（窗口大小8），避免战力突变导致难度剧烈波动
4. 难度上下限：70%~200%基准难度
5. 50关后渐进式难度增长：每10关+5%基础难度
6. 伤害和速度缩放也采用Sigmoid平滑

### 战力上限

**问题描述**：
- 需要限制战力数值但不使用log函数

**实现方案**：
1. 战力硬上限设为100,000（使用Math.min，不使用log函数）

### 排行榜重置

**问题描述**：
- 战力系统重构后旧排行榜数据不再有参考价值

**实现方案**：
1. 所有旧版本排行榜数据标记为 last=true（仅标记2026-03-19之前的数据）
2. 新数据 last=false，排行榜只显示新版本数据
3. 首页增加重置横幅，显示到2026-03-21
4. 新增 markAllAsLast() API方法，含created_at截止时间过滤
