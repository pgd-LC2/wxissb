## 主要更新

### 1. 飞刀数量UI显示
- 在游戏HUD中增加飞刀数量显示（🔪 飞刀: X）
- 实时更新飞刀数量
- 玩家无飞刀时自动隐藏

### 2. 难度系统重构（Sigmoid平滑曲线）
- 使用Sigmoid函数替代原有线性难度计算
- 战力影响通过Sigmoid函数压缩到0.5-1.5范围
- 最终难度 = 基准难度 * (0.8 + clampedRatio * 0.7)
- 新增滑动平均战力（窗口大小8），避免战力突变导致难度剧烈波动
- 难度上下限：70%~200%基准难度
- 50关后渐进式难度增长：每10关+5%基础难度
- 伤害和速度缩放也采用Sigmoid平滑

### 3. 战力上限
- 战力硬上限设为100,000（不使用log函数）

### 4. 排行榜重置
- 所有旧版本排行榜数据标记为 last=true
- 新数据 last=false，排行榜只显示新版本数据
- 首页增加重置横幅，显示到2026-03-21

### 5. Supabase API
- 新增 markAllAsLast() 方法，用于版本更新时清理旧排行榜数据

## 技术细节

### Sigmoid难度算法
```
smoothedPower = 滑动平均战力（最近8次）
expectedPower = 50 + (level - 1) * 100
rawPowerRatio = smoothedPower / expectedPower
sigmoid = 1 / (1 + exp(-4 * (rawPowerRatio - 1)))
clampedRatio = 0.5 + sigmoid  // 范围 0.5~1.5
finalDiff = baseDiff * (0.8 + clampedRatio * 0.7)
finalDiff = clamp(finalDiff, baseDiff * 0.7, baseDiff * 2.0)
```

### 后期难度递增
```
level > 50 时：baseDiff *= (1 + floor((level-50)/10) * 0.05)
```
