# 版本 1.7.9 更新日志

**发布日期**: 2026-04-16

## 新增功能 / 修复内容

### 重构前端文件架构

**问题描述**：
- 旧架构存在页面脚本内联、基础设施散落在根目录、小功能拆得过碎、复杂功能堆进超大文件的问题，后续维护和继续拆分成本很高。

**修复方案 / 实现方案**：
1. 将首页和排行榜页改为外部脚本入口，页面层不再把主要逻辑直接写在 HTML 中。
2. 拆分 Supabase 配置、客户端、排行榜接口、技能举报接口、偏好存储与玩家名存储，建立 `js/content`、`js/infra`、`js/app` 基础目录。
3. 将职业武器系统拆为职业/武器数据、选择状态、属性应用器和选择 UI 四层，并改为通过 `GameApp.ClassWeaponSystem` 统一装配。
4. 将技能系统中的赛博技能与飞刀技能迁移到 `js/content/skills/`，将 `skills.js` 收敛为基础技能聚合层。
5. 将暂停页与结算页共享的技能卡片、战绩摘要、技能举报逻辑抽到 `js/ui/shared/`，并将声音/音乐/震动开关合并到 `js/ui/game/controls.js`。
6. 从 `js/core/gameFactory.js` 拆出战力评估、技能抽取和渲染系统；从 `js/magicSystem.js` 拆出魔法钩子层；将 `pages/game.html` 改为按层加载新目录结构中的脚本。
