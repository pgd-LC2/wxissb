# 版本 1.7.12 更新日志

**发布日期**: 2026-04-16

## 新增功能 / 修复内容

### 文件架构重构：继续去除单文件目录

**问题描述**：
- 代码仓库仍存在若干只有一个脚本文件的目录，加载入口依赖深层路径，目录维护成本偏高。
- 同时，首页与排行榜入口的脚本路径仍引用旧的 `app/bootstrap` 目录。

**修复方案 / 实现方案**：
1. 将单文件目录中的脚本向父目录拉平：
   - `js/render/renderWithCssSize.js` -> `js/renderWithCssSize.js`
   - `js/systems/render/gameRenderer.js` -> `js/gameRenderer.js`
   - `js/canvas/resize.js` -> `js/canvas.js`
   - `js/loop/tick.js` -> `js/gameLoop.js`
   - `js/app/bootstrap/homeEntry.js` -> `js/homeEntry.js`
   - `js/app/bootstrap/leaderboardEntry.js` -> `js/leaderboardEntry.js`
   - `js/app/bootstrap/gameEntry.js` -> `js/gameEntry.js`
2. 清理并移除已空目录：`js/app`、`js/render`、`js/canvas`、`js/loop`、`js/systems/render`。
3. 更新入口加载路径：
   - `js/gameEntry.js`（动态脚本加载列表）
   - `index.html`
   - `pages/leaderboard.html`
   - `pages/game.html`
