# 版本 1.6.0 更新日志

**发布日期**: 2026-03-18

## 怪物生成系统重构

- **移除**旧的复杂怪物生成机制（基于 combat rating、等级、存活时间、难度乘数等）
- **新增**基于玩家击杀率的怪物生成系统：
  - 使用10秒滚动窗口追踪玩家击杀数
  - 核心公式：`spawnRate = 1.5 + killsPer10s × 0.3`
    - 基础生成速率：1.5 敌人/秒
    - 每击杀1个敌人/10秒 → 额外+0.3 敌人/秒
  - 无上限、无下限，纯击杀率驱动
  - 示例：0击杀 → 1.5/秒，10击杀 → 4.5/秒，30击杀 → 10.5/秒
- 保留：NB模式、Boss生成、敌人属性缩放（HP/伤害/速度）

## 死亡界面 UI 美化

- 全新的视觉层级设计：
  - 骷髅头动画 + GAME OVER 标题 + 段位徽章
  - 大号战力评分展示区（带段位颜色高亮）
  - 四宫格数据卡片：存活时间、击杀数、等级、技能数
  - 详细数据行：平均战力、峰值战力、本地排名
- 响应式布局：移动端自动调整为2列卡片网格
- 使用 CSS class 替代内联样式，提升可维护性

## 死亡界面举报技能功能

- 新增「举报技能」入口按钮
- 技能举报面板（动态生成，仅死亡界面可见）：
  - 显示当局获得的所有技能（含图标和描述）
  - 支持多选技能
  - 举报理由选择：没用、太弱、效果不明显、其他
  - 「其他」理由支持补充说明文本
  - 通过 Supabase API 提交举报
- 所有用户输入均使用 `escapeHtml()` 进行 XSS 防护

**修改文件**：
- `js/core/gameFactory.js` - 怪物生成系统重构（击杀率驱动）
- `js/ui/gameover.js` - 死亡界面 UI 美化 + 举报技能功能
- `js/core/dom.js` - DOM 引用清理
- `css/styles.css` - 新增死亡界面样式
- `pages/game.html` - 移除静态举报面板
- `version.txt` - 版本号更新
