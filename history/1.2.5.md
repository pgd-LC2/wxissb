# 版本 1.2.5 更新日志

**发布日期**: 2026-01-31

## 新增功能 / 修复内容

### 联机模式修复

**问题描述**：
1. **画面拖尾/重影**：联机模式下画面渲染时，由于 Canvas 变换矩阵与清屏操作的顺序或范围问题，导致上一帧的内容未被完全清除，产生拖尾。
2. **自动缩放失效**：动态相机缩放逻辑虽然存在，但在某些情况下（如玩家距离边缘不够远或 DPR 计算问题）未能正确触发缩小，导致玩家可能在视野外。
3. **缩放/显示异常**：`ctx.save()` 和 `ctx.restore()` 依赖外部的变换状态（由 `resize.js` 设置），这在复杂的缩放逻辑下可能导致状态混乱。

**修复方案 / 实现方案**：
1. **重置渲染状态**：在每一帧渲染开始时，强制使用 `ctx.setTransform(1, 0, 0, 1, 0, 0)` 重置变换矩阵，并清除整个 Canvas（使用物理像素尺寸），确保画面完全干净，彻底解决拖尾问题。
2. **重构动态缩放**：
   - 增加相机边缘 Padding（从 150 增加到 200）。
   - 修正缩放计算公式，正确处理 DPR (Device Pixel Ratio)，确保逻辑坐标与物理坐标的转换正确。
   - 确保当玩家距离拉大时，相机能平滑缩小（Zoom Out）以容纳所有玩家。
3. **手动管理变换**：不再依赖 `resize.js` 设置的全局变换，而是在 `render` 函数内部完全控制 `translate` 和 `scale`，确保渲染结果的一致性和正确性。
