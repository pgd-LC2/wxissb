# 版本 1.2.3 更新日志

**发布日期**: 2026-01-31

## 新增功能 / 修复内容

### 联机模式修复与优化

**问题描述**：
1. **界面异常放大**：联机模式下画面渲染使用了物理像素尺寸，导致在高 DPI 屏幕上画面被错误放大。
2. **血条/经验条为空**：HUD 更新逻辑使用了错误的 CSS 选择器，无法匹配到 HTML 中的元素。
3. **FPS 不显示**：联机模式缺少 FPS 统计逻辑。

**修复方案 / 实现方案**：
1. **修复渲染缩放**：修改 `multiplayerGameFactory.js` 中的渲染逻辑，使用 `GameApp.Canvas.getCssSize()` 获取正确的 CSS 像素尺寸，确保画面在所有设备上比例正常。
2. **动态相机**：新增动态相机功能。当队友离开当前视野时，相机会自动缩放（Zoom Out）以确保所有玩家尽可能都在视野范围内。
   - 根据所有存活玩家的位置计算边界框。
   - 动态调整缩放比例，最小缩放限制为 0.4x。
   - 始终保持以玩家群组的中心点为视角中心。
3. **修复 HUD**：更新 `lobby.js` 中的 HUD 更新逻辑，使用正确的 ID (`hpFill1`, `hpFill2` 等) 来更新血条和经验条。
4. **添加 FPS 计数**：在 `multiplayerTick.js` 中集成 FPS 统计逻辑，实时显示帧率。

**修改文件**：
- `wxissb/js/multiplayer/multiplayerGameFactory.js`
- `wxissb/js/multiplayer/lobby.js`
- `wxissb/js/multiplayer/multiplayerTick.js`
