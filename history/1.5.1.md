# 版本 1.5.1 更新日志

**发布日期**: 2026-03-17

## 新增功能

### 暂停菜单重构 & 举报技能功能

**功能描述**：
- 重构暂停菜单，降低密度，提升视觉效果
- 新增"举报技能"功能，允许玩家举报认为"没用"的技能
- 暂停菜单左右两侧添加酷炫的技能滚动展示动画
- 新增背景粒子特效系统

**实现方案**：
1. 重构暂停菜单 HTML 结构，添加左右技能滚动列和粒子画布
2. 全新 CSS 样式：径向渐变背景、玻璃拟态面板、技能卡片等级发光
3. 左右技能滚动列：无限循环滚动动画，带淡入淡出遮罩
4. 技能卡片按等级显示不同发光效果（传说级有呼吸光效）
5. 举报面板：技能多选、理由选择（没用/太弱/效果不明显/其他）、补充说明
6. 举报数据提交到 Supabase skill_reports 表
7. 背景粒子系统：50个金色粒子浮动，带发光效果
8. ESC 键支持：在举报面板时先返回主面板，再关闭暂停菜单

**数据库变更**：
- 新建 `skill_reports` 表，字段包括：技能名称、等级、举报理由、补充说明、玩家名、游戏等级、游戏分数
- 启用 RLS，仅允许匿名用户插入

**修改文件**：
- `pages/game.html` - 重构暂停菜单 HTML 结构
- `css/styles.css` - 全新暂停菜单样式和动画
- `js/core/dom.js` - 注册新 DOM 元素
- `js/supabase.js` - 新增 submitSkillReport 方法
- `js/ui/pause.js` - 完全重写，添加举报逻辑和酷炫特效
- `version.txt` - 版本号更新至 1.5.1
