# 版本 1.2.1

## 发布日期
2026-01-31

## 修复内容

### Bug 修复

1. **修复 Host 无法启动游戏的问题**
   - 问题：Host 点击"开始游戏"后，由于 Supabase broadcast 不会回传给发送者，导致 Host 的 `onGameStart` 回调永远不会被触发
   - 影响：多人游戏无法正常启动，Host 会停留在等待界面
   - 修复：在 `room.js` 的 `startGame()` 方法中，广播后手动触发 Host 自己的 `onGameStart` 回调

2. **修复 Host 选择技能时效果被应用两次的问题**
   - 问题：Host 选择技能时，`selectSkillForPlayer()` 被调用两次（一次在 `multiplayerTick.js` 的 `sendSkillPick()`，一次在 `lobby.js` 的 `selectSkill()`）
   - 影响：Host 玩家获得双倍技能效果，破坏游戏平衡
   - 修复：移除 `lobby.js` 中重复的技能执行代码，因为 `sendSkillPick()` 已经处理了 Host 的本地执行

3. **修复经验球位置除零错误的问题**
   - 问题：当玩家恰好站在经验球位置时，距离 `dist` 为 0，导致除零产生 NaN 值
   - 影响：经验球位置变为 NaN 后无法被拾取，可能导致渲染异常
   - 修复：在 `multiplayerGameFactory.js` 的 `updateExpOrbs()` 中添加 `dist > 0` 的检查

## 修改的文件

- `js/multiplayer/room.js` - 修复 Host 启动游戏问题
- `js/multiplayer/lobby.js` - 移除重复的技能执行
- `js/multiplayer/multiplayerGameFactory.js` - 添加除零保护
