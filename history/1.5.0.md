# 版本 1.5.0 更新日志

**发布日期**: 2026-03-17

## 新增功能

### Boss系统

**功能描述**：
- 新增5个Boss敌人类型，每个Boss拥有独特的外观、属性和AI行为
- Boss每隔8级自动出现一次，按顺序轮换

**Boss列表**：
1. **泰坦** - 高血量高护甲的重型Boss，缓慢但致命
2. **风暴领主** - 快速环绕型Boss，拥有远程射击能力
3. **虫巢母体** - 超高血量的召唤型Boss，持续生成小怪
4. **幻影刺客** - 极速冲锋型Boss，高伤害但血量较低
5. **钢铁堡垒** - 超厚护甲的防御型Boss，拥有远程攻击

### 怪物属性动态缩放

**功能描述**：
- 怪物的血量和伤害现在会根据玩家的攻击力动态缩放
- 使用对数缩放公式（log2），攻击力每翻倍，怪物难度增加一个档次
- Boss类型享受额外的攻击力缩放加成，确保后期Boss不会被秒杀
- 防止玩家在后期通过高攻击力轻松挂机通关

**技术细节**：
- `d.diff`（怪物HP缩放）上限从8.0提升到16.0
- `d.dmgMul`（怪物伤害缩放）上限从5.0提升到8.0
- Boss HP上限从200000提升到500000
