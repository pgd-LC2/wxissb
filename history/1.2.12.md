# 版本 1.2.12 更新日志

**发布日期**: 2026-02-05

## 新增功能 / 修复内容

### 全设备摇杆显示控制

**问题描述**：
- 用户希望在所有设备（包括手机、平板、电脑）上都显示“是否开启虚拟摇杆”的询问对话框，以便自主选择。之前版本要么只针对电脑，要么强制隐藏。

**修复方案 / 实现方案**：
1. 修改 `js/input/joystickDialog.js`：
   - 移除 `isDesktopDevice` 检测，使 `initJoystickForDesktop` 逻辑在所有设备上运行。
   - 更新对话框提示文案，去除特定于电脑的描述。
   - 恢复之前的询问逻辑。
2. 修改 `css/styles.css`：
   - 移除 `#joystick` 的 `display: none !important`，改为默认 `display: none`。
   - 移除（保持注释状态）针对触摸设备的自动显示媒体查询，确保摇杆显示完全由 JS 逻辑控制。

**修改文件**：
- `js/input/joystickDialog.js`
- `css/styles.css`
- `version.txt`
